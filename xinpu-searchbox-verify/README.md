# 鑫浦 · 聊天搜索框二次校验（对账第一锚点 · 标准流程）

> 顾超 2026-11-21 令：聊天搜索框调取**带时间戳的原始交易记录** = 对账第一锚点。
> 对账时先输入订单金额或编号，调取原始记录，与工作台、账面数据做**三账比对**；
> 不一致时自动标记「优先取搜索框结果」，确认无误再推进流程。

## 三账口径
- 账A 聊天搜索框原话（第一锚点）：镜像倒排检索 `<家名>合计需付款： NNNN`
- 账B 工作台：`数字唯一源.json`（工作台页面唯一出处）
- 账C 账面：`锚台账.json` ＋ `付款核对_<账期>.json`

## 用法
```bash
# 账期全量（默认读数字唯一源当前账期）
python 搜索框二次校验.py

# 订单告警单查（外挂接口：拉带时间戳原始记录 + 三账比对）
python 搜索框二次校验.py --q 1614 --家 鑫隆

# 告警数字批量
python 搜索框二次校验.py --nums 1614,3228 --家 鑫隆

# 任意账目 json
python 搜索框二次校验.py --json <path>
```
